# Mechinagar Local

Nepali-first local information platform for Mechinagar Municipality, Jhapa. See the planning docs in the repo root (`PRODUCT_REQUIREMENTS.md`, `MVP_SCOPE.md`, etc.) for the product spec.

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Content in `src/lib/data/` is mock/sample data for the MVP visual foundation — see `/about` on the site for the standing disclosure note.

## Stack

Next.js (App Router) · React · TypeScript · Tailwind CSS
